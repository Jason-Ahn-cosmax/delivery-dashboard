# 납기준수율 / 수량완납율 대시보드

고객사별 월별 **납기준수율**(on-time delivery)과 **수량완납율**(quantity fulfillment)을 추적하는 HTML 대시보드. 두 가지 운영 모드를 지원합니다.

| 모드 | 특징 | 사용 시점 |
|---|---|---|
| **로컬 모드** | 브라우저 `localStorage`에 저장, 본인 PC에서만 보임 | 혼자 분석용, 또는 백엔드 설정 전 |
| **서버 모드** | Google Sheets 백엔드와 동기화, URL만 알면 누구나 최신 데이터 조회 | 팀 배포용 (권장) |

## 빠른 시작 (로컬 모드)

1. `delivery-dashboard.html` 파일을 더블클릭 (또는 브라우저로 열기)
2. **데이터 업로드** 탭에서 정해진 양식의 `.xlsx` 파일을 끌어다 놓기
3. 다른 탭에서 자동으로 집계된 차트/표를 확인

데이터는 브라우저 `localStorage`에 저장되어 **같은 PC + 같은 브라우저**에서만 유지됩니다.

## 팀 배포 (서버 모드)

Google Sheet를 백엔드로 두고 Vercel로 호스팅하는 구조입니다.

```
[업로더]                              [동료 N명]
  ↓ 엑셀 업로드                          ↓ URL 접속
[브라우저 HTML] ─── POST(token) ─── [Apps Script Web App]
                                          ↓
                                   [Google Sheet]
                                          ↑
[브라우저 HTML] ─── GET ────────── [Apps Script Web App]
```

설정 방법은 [`apps-script/SETUP.md`](./apps-script/SETUP.md)에 단계별로 정리되어 있습니다 (약 15분 소요).

## 엑셀 양식 (업로드 파일 요구사항)

워크북에 다음 시트들이 있어야 하며 시트명은 정확히 일치해야 합니다.

### `Raw data` 시트 (필수)

1행은 헤더, 2행부터 데이터. 컬럼은 알파벳 위치로 읽으므로 순서를 바꾸지 마세요.

| 열 | 내용 | 예시 |
|---|---|---|
| A | 고객사 | `LOJ` |
| B | 연도 | `2025` |
| C | 월 | `3` |
| D | PO 번호 | |
| E | PO 상세 | |
| F | 영업문서 | |
| G | 품목 | |
| H | 자재코드 | |
| I | 자재명 | |
| J | 발주수량 | |
| K | 납품수량 | |
| L | 발주일 | |
| M | 최초 납기일 | |
| N | 납기+30일 | |
| O | 자재입고일 | |
| P | 생산완료일 | |
| Q | 최종납품일 | |
| R | 리드타임 | |
| S | 자재리드타임 | |
| T | 준수여부 | `준수` / `미준수` |
| U | 납기지연 주체 | 미준수일 때 원인 분류 |
| V | 지연 상세 | |

T열이 `준수`면 준수 카운트, 그 외는 모두 미준수로 분류됩니다.

### `우선순위` 시트 (선택)

연도별 고객사 우선순위. 셀 주소로 직접 읽으므로 위치 고정:
- `G2:G21` — 순위 (1~20)
- `H2:H21` — 2025년 해당 순위 고객사명
- `I2:I21` — 2026년 해당 순위 고객사명

### `납기준수율목표` 시트 (선택)

A열 = 연도, B열 = 목표 %. 값이 1 이하면 비율(예: `0.85`)로 간주해 100을 곱합니다.

## 탭별 기능

| 탭 | 설명 |
|---|---|
| **대시보드** | 연도/월/고객사 필터, KPI 카드, 월별 추이 차트, 고객사 비교 (목표 달성/미달), 월×고객사 교차표 |
| **고객사별 상세** | 고객사 단위로 월별 추이, 상세 표, 건별 raw data 필터링 |
| **지연 분석** | 미준수 건 추이, 납기지연 주체별 분포, 고객사별 미준수 건수, 건별 상세 |
| **Summary** | AS-IS / TO-BE 두 시점 비교, KPI 변동, 주체별 변동, 자동 코멘트 + 클립보드 복사 |
| **데이터 업로드** | 엑셀 업로드, 업로드 이력, 연도별 목표 설정, 백업/복원, 팀 공유 파일 생성 |

## 공유 및 백업

- **팀 공유용 파일 생성** — 현재 데이터가 박힌 단독 HTML을 다운로드. 받은 사람도 `localStorage` 없이 곧바로 열어볼 수 있습니다.
- **전체 백업 (JSON)** — 모든 상태(`dd_*` 키)를 JSON으로 내보내기.
- **백업 복원** — JSON 파일을 불러와 상태 복원.
- **전체 초기화** — 브라우저의 모든 대시보드 상태 삭제 (되돌릴 수 없음).

## 저장 키 (참고)

`localStorage` 내 키:
- `dd_raw_data` — 업로드된 raw 행 배열
- `dd_priority` — 연도별 고객사 순위 (`{ "2025": {...}, "2026": {...} }`)
- `dd_targets` — 연도별 납기준수율 목표
- `dd_targets_qr` — 연도별 수량완납율 목표
- `dd_upload_history` — 최근 10건 업로드 이력

## 기술 스택

- 순수 HTML + JavaScript (빌드 도구 없음)
- [Chart.js 4.4.7](https://www.chartjs.org/) — 차트
- [SheetJS / xlsx 0.18.5](https://sheetjs.com/) — 엑셀 파싱
- 모든 라이브러리는 CDN 로드 → 인터넷 연결 필요
